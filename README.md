🍽️ Food Menu Search Website

A colorful and interactive Food Menu Web Page built using HTML, CSS, and JavaScript.
This project displays food items, categories, prices, and availability using a styled table with a live search filter feature.

📌 Project Overview

The Food Menu Search Website allows users to view a restaurant menu and quickly find food items using a search box.
The interface uses modern UI styling including gradients, hover effects, and category color tags.

🔎 How Search Works

User enters text in the search box.

JavaScript reads the input value.

Each table row is checked for matching content.

Matching rows remain visible while others are hidden.
